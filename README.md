UNIVERSIDAD INTERCULTURAL PARA LA IGUALDAD

PROYECTO ABRAZA UN ARBOL

La problemática que se analizo para este proyecto fue la escases de arboles en la comunidad de MONTE VERDE, SAN FCO. DE LOS ROMO, AGS.
Nos dimos a la tarea de analizar el territorio e investigar en las instituciones la posibilidad de la donación de arboles, la cual fue 
lograda nos facilitaron varias plantas para darlas en adopción a las personas. 

MODELO DE BASE DE DATOS

*Diagrama Entidad-Relación (DER)

*Esquema Relacional de Tablas Normalizado hasta la Tercera Forma Normal (3FN) con tipos de datos, llaves primarias (PK) y llaves foráneas (FK) claramente especificadas

*DB Browser para SQLite sentencias.

*Estructura del INNER JOIN, GROUP BY, cruces y agrupaciones.

ANALISIS EXPLORATORIO (R)

-Automatiza tareas repetitivas: Renombrar cientos de archivos, organizar carpetas o hacer copias de seguridad de forma automática.

-Permite que los sitios web reaccionen a los clics del usuario, validen formularios o actualicen contenido sin recargar la página.

-A diferencia de un programa tradicional que necesita compilarse por completo antes de funcionar, el script se lee y se ejecuta paso a paso.
